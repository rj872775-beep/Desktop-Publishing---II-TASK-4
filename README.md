# Desktop-Publishing---II-TASK-4
Click Select → Select and Mask to refine the selection edges.
Adjust Smooth, Feather, Contrast, and Shift Edge as required.
Create a Brightness/Contrast Adjustment Layer using Layer → New Adjustment Layer → Brightness/Contrast.
Adjust brightness and contrast to improve the subject's appearance.
Create a second Hue/Saturation Adjustment Layer.
Adjust Hue, Saturation, and Lightness to modify colors.
Use the adjustment layer masks to control where the effects appear.
Paint with black on a mask to hide an adjustment and white to reveal it.
Keep the original photograph unchanged.
Arrange the original and edited photographs side by side using the Move Tool (V).
Add BEFORE and AFTER labels using the Type Tool (T).
Save the project as Photo_Editing.psd.
Export the final composition as a JPEG or PNG using File → Export → Export As.
